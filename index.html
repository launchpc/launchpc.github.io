FAQ

Questions

Is LaunchPC free?

Yes, it's free to download and use.

Will it delete my files without asking?

Never. You choose what to remove, LaunchPC asks first, and removed files go to the Recycle Bin so you can restore them.

Windows says "Windows protected your PC". Is that normal?

Yes. Windows shows this for new apps it hasn't seen many times before. Click "More info", then "Run anyway".

Is Quick boost one of those RAM boosters?

No. It doesn't play tricks with your memory. It shows the heavy apps you have open, closes only the ones you pick (they can ask you to save first), and clears temporary files.

How do I get updates?

LaunchPC checks for new versions when it opens. When one is out, click "Update now" and it updates itself.

Which Windows versions does it work on?

Windows 10 and Windows 11, 64-bit. It uses Microsoft Edge, which is already part of Windows, to draw its window.

What does "Beta" mean?

LaunchPC is new and still getting better. Everything works, but you might spot rough edges. New versions arrive through in-app updates.

Found a bug or have an idea?

Great! Use the "Report a bug" or "Suggest an idea" buttons below. You'll need a free GitHub account.
